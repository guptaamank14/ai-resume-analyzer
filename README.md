# 🌟 Overview

AI Resume Analyzer is a production-ready full-stack web application that
analyzes resumes using Google Gemini AI. It calculates ATS scores,
compares resumes against job descriptions, identifies missing skills,
and generates personalized interview questions.

------------------------------------------------------------------------

# ✨ Features

  Feature               Description
  --------------------- ---------------------------------------------
  ATS Resume Analysis   AI-powered ATS score with recommendations
  Resume Parsing        Upload PDF/TXT resumes
  JD Matching           Compare resume with job description
  Skill Gap Analysis    Detect missing skills
  AI Interview Prep     Generate technical & HR interview questions
  Authentication        JWT login & registration
  Dashboard             Track analysis history
  Dark Mode             Responsive modern UI

# 🚀 Installation

``` bash
git clone https://github.com/guptaamank14/ai-resume-analyzer.git
cd ai-resume-analyzer
```

## Backend

``` bash
cd backend
npm install
npm run dev
```

## Frontend

``` bash
cd frontend
npm install
npm run dev
```
